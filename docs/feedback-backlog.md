# AIX consolidated feedback backlog

Updated 2 November 2026. This is the source-of-truth backlog distilled from the user's feedback, [the source audit](audit-2026-10-29.md), and [meeting feedback](product-feedback-2026-11-02.md). **Existing** means there is an implementation to preserve; it does not certify the whole journey. **Open** means unfinished. **In progress** means changes are not yet accepted as complete. Historical QA reports are evidence with stated scope, not blanket completion.

Priorities: **P0** = access or execution trust boundary; **P1** = a first useful, returnable job; **P2** = broaden dependable work; **P3** = distribution/launch expansion. Work may proceed independently when it does not depend on an unresolved boundary. Do not reset existing work or migrate the whole application to a framework.

## Delivery checkpoints (existing foundations)

1. Preserve a reproducible baseline and close trust boundaries.
2. Complete a returnable transcript job with visible source scope, progress, table and history.
3. Complete a visible bounded coordinator/parallel-specialist job.
4. Add automatic responsibility triggers and notification only after source access and execution states are proven.
5. Broaden evals, browser/channel automation and production operations without replacing the platform wholesale.

The selective Mastra slice addresses only part of **MEET-01**. On 30 October 2026, the embedded extraction tool passed 63 automated tests, 15 API integration groups, TypeScript and production Docker build checks. The saved transcript agent was updated and reloaded in the browser. See [verification evidence](selective-framework-qa-2026-10-30.md). It does not close **MEET-02**, **RUN-02**, personal Scribe authorization, live model quality or the history/activity backlog.
